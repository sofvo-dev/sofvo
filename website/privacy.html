プライバシーポリシー

最終更新日: 2026年3月10日

Sofvo（以下「当サービス」）は、ユーザーの個人情報の保護を重要視しています。本プライバシーポリシーは、当サービスにおける個人情報の取り扱いについて説明します。

1. 収集する情報

当サービスでは、以下の情報を収集する場合があります。

1.1 ユーザーが提供する情報

情報の種類利用目的
メールアドレスアカウント認証・重要なお知らせ
ニックネーム・プロフィール情報サービス内での表示・マッチング
プロフィール画像サービス内での表示
投稿内容（テキスト・画像）コミュニティ機能の提供
チャットメッセージコミュニケーション機能の提供

1.2 自動的に収集される情報

  • 端末情報（OS、バージョン）
  • 利用状況データ（アクセス日時、利用機能）

2. 情報の利用目的

収集した情報は、以下の目的で利用します。

  1. 当サービスの提供・運営・改善
  2. ユーザーからのお問い合わせへの対応
  3. 利用規約に違反する行為への対応
  4. 当サービスに関する重要なお知らせ
  5. 新機能・更新情報のご案内
  6. 統計データの作成（個人を特定できない形式）

3. 情報の共有・第三者提供

当サービスは、以下の場合を除き、ユーザーの個人情報を第三者に提供しません。

  • ユーザーの同意がある場合
  • 法令に基づく場合
  • 人の生命、身体または財産の保護のために必要がある場合
  • サービス提供に必要な業務委託先への提供（Firebase / Google Cloud 等）

各サービスのプライバシーポリシーについては、それぞれの提供元のWebサイトをご確認ください。

4.1 Google Analytics について

当サービスでは、利用状況の分析およびサービス改善のためにGoogle Analytics for Firebaseを使用しています。Google Analyticsは、端末識別子やアプリの利用状況に関するデータを収集します。収集されたデータはGoogleのプライバシーポリシーに基づき管理されます。Google Analyticsによるデータ収集の詳細は、Google のパートナーサイトのプライバシーをご確認ください。

4.2 Amazon Product Advertising API について

用具管理機能において、Amazon Product Advertising APIを利用して商品情報（商品名、画像、価格等）を取得・表示しています。ユーザーの個人情報はAmazonに送信されません。商品リンクにはアフィリエイトタグが含まれる場合があります。

5. データの保管とセキュリティ

  • ユーザーデータはGoogle Cloudのインフラ上に暗号化して保管されます。
  • Firebase Security Rulesにより、ユーザーは自身のデータのみアクセス可能です。
  • パスワードはFirebase Authenticationにより安全にハッシュ化されています。
  • データの転送時にはSSL/TLS暗号化を使用しています。

5.1 データの保管場所（国際データ移転）

当サービスで収集したデータは、Google Cloud / Firebase のサーバー上に保管されます。これらのサーバーは日本国外（米国等）に所在する場合があります。当サービスを利用することにより、ユーザーはデータが日本国外のサーバーに転送・保管されることに同意したものとみなします。

5.2 データの保持期間

ユーザーのアカウント情報および関連データは、アカウントが有効な間保持されます。アカウント削除が行われた場合、ユーザーの個人データは30日以内に削除されます。ただし、法令により保持が義務付けられている場合、または正当な事業上の理由がある場合（不正利用対策等）は、必要最小限の期間保持する場合があります。利用状況の統計データは、個人を特定できない匿名化された形で保持される場合があります。

6. ユーザーの権利

ユーザーは以下の権利を有します。

  1. データの閲覧：アプリ内のマイページからご自身の情報を確認できます。
  2. データの修正：プロフィール編集画面から情報を修正できます。
  3. データの削除：設定画面の「アカウント削除」からデータを完全に削除できます。
  4. 通知の管理：設定画面から通知の受信設定を変更できます。

7. Cookie等の使用

当サービスのWeb版では、認証情報の保持のためにブラウザのローカルストレージを使用する場合があります。

8. 子どものプライバシー

当サービスは13歳未満のお子様を対象としていません。13歳未満のお子様から個人情報を収集していることが判明した場合、速やかに該当情報を削除します。

9. プライバシーポリシーの変更

当サービスは、必要に応じて本ポリシーを変更することがあります。重要な変更がある場合は、当サービス上でお知らせします。変更後のポリシーは、当ページに掲載された時点から効力を生じます。
