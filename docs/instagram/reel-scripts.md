# Sofvo リール ナレーション台本

1機能=1リール（共感フック型）。生成は `tools/ig-carousel/reel-single.mjs`（`REEL=<key>`）。
映像は無音MP4。下記ナレーションを録音して乗せ、Instagramでトレンド音源を小さめに重ねる運用。

収録のコツ:
- フックは少し煽り気味・語りかけで（スクロールを止める一言）
- 解決パートは明るくテンポよく、「リアルタイム」「自動」を強調
- CTAはゆっくり丁寧に。最後の「ぜひ」で柔らかく締め
- BGM（トレンド音源）はナレーションより小さめに
