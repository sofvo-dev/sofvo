# Sofvo リール ナレーション台本

1機能=1リール（共感フック型）。生成は `tools/ig-carousel/reel-single.mjs`（`REEL=<key>`）。
映像は無音MP4。下記ナレーションを録音して乗せ、Instagramでトレンド音源を小さめに重ねる運用。

### ★ElevenLabs 読み上げ注意（ナレーションを貼る前に）
- **「…」は使わない**＝「テンテンテン」と読まれる。間は **「、」「。」** に、はっきり溜めたい所は **`<break time="0.4s" />`**（v2有効）。※キャプション側の「…」は人が読むだけなのでOK。
- **「Sofvo」は「ソフボ」**とカナ入力。**頭高（ソを高く）**にしたい場合は綴りで誘導：`ソ・フボ`（中黒で頭高・音はソフボのまま／第一候補）／`ソゥフボ`／`ソッフォ`（音がso-ffo寄り）。`ソフボー`等の語尾伸ばしは尾が上がるので避ける。固定したいなら Studio の Pronunciation Dictionary で `ソフボ`→エイリアス登録。
- 設定：Multilingual v2／Stability 40〜50%・少しゆっくり、声はシリーズで統一（Yui等）。
