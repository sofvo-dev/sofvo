# Canva Pro で半自動運用（採用ツール）

Canva Pro を使い、**AIが書いた文章（CSV）をテンプレに一括流し込み（Bulk Create）→
Instagramへ予約**する。コストは追加ゼロ（Pro内の機能のみ）。

```
文章CSV（AI/Claudeが作成：carousels.csv）
   → Canvaでテンプレ1個作成（5ページ）
   → Bulk Create で一括生成（全カルーセルが自動でできる）
   → コンテンツプランナーで予約
```

あなたの作業：テンプレ初回作成 → 一括生成 → 予約。文章作成はゼロ。

---

## STEP 1. ブランドキット登録（1回だけ）

Canva 左メニュー **「ブランド」→ ブランドキット** で登録：

| 項目 | 値 |
|---|---|
| カラー | ネイビー `#1B3A5C` / クリーム `#F7F5EF` / ゴールド `#C4A962` / 白 `#FFFFFF` |
| フォント（見出し） | `Dela Gothic One`（極太・検索して追加） |
| フォント（本文） | `Noto Sans JP` |
| ロゴ | `website/images/app_icon_512.png` をアップロード |

---

## STEP 2. カルーセル・テンプレを作る（5ページ）

1. **新規デザイン → Instagram投稿（正方形 1080×1080）** を作成。
2. ページを **5枚** にする（表紙＋中3枚＋CTA）。
3. 各ページに**テキスト枠**を置き、ブランドの色・フォントを設定。
4. 各テキスト枠を、CSVの列名と同じ「データ項目」に対応させる（STEP 3で接続）。

### 各ページの構成（背景は1・3・5をネイビー、2・4をクリームで市松に）

| ページ | 置くテキスト枠（＝CSV列） | デザイン |
|---|---|---|
| 1 表紙 | `pill`（小） / `cover_title`（極太・大） / `cover_sub` | 背景ネイビー・文字白・pillはゴールド帯 |
| 2 | `s2_title`（太） / `s2_body` | 背景クリーム・文字ネイビー・角丸カード |
| 3 | `s3_title` / `s3_body` | 背景ネイビー・文字白・角丸カード |
| 4 | `s4_title` / `s4_body` | 背景クリーム・文字ネイビー・角丸カード |
| 5 CTA | `cta_title`（太） / `cta_sub` / ロゴ | 背景ネイビー・文字白・CTAはゴールド |

### 全ページ共通（毎回固定＝統一感の核）
- **下部にフッターバー**（濃紺帯）：♥ ＋「ソフトバレーを、もっと楽しく。」＋🔖
- **右下にSofvoロゴ**（小さく・位置固定）

> このテンプレは1回作れば、以後ずっとコピーして使い回す。

---

## STEP 3. Bulk Create で一括生成（自動化の肝）

1. 左メニュー **「アプリ」→「一括作成（Bulk Create）」** を開く。
2. **「データをアップロード」→ CSV** を選び、`docs/instagram/canva-bulk/carousels.csv` を読み込む
   （または「データを手動で入力」に貼り付け）。
3. 各テキスト枠を**右クリック → 「データを接続」**で、対応する列（`cover_title` など）を割り当てる。
4. **「続行 → 12件生成」** を押す → **全12カルーセルが一括で自動生成**される🎉
5. 生成物をざっと確認（日本語の崩れ・はみ出しが無いか）。長い文は枠を「自動サイズ調整」に。

---

## STEP 4. コンテンツプランナーで予約

1. 左メニュー **「コンテンツプランナー」** を開く（カレンダー）。
2. Instagram（`sofvo.official`／プロアカウント）を**連携**。
3. 生成したカルーセルをカレンダーの日付に置く → **本文（キャプション）を貼る**
   （`docs/instagram/canva-bulk/captions.md` の同じ番号をコピペ）。
4. 時間を指定して**予約**。週1〜2本ペースで並べる。
   → これで「自分は予約だけ」が完成。

---

## 運用サイクル（続けるコツ）

1. 月初に Claude（このリポジトリ）へ「次の12本のCSV作って」と頼む → `carousels.csv` 更新。
2. Canva の Bulk Create で一括生成。
3. コンテンツプランナーでまとめて予約。
4. 写真が貯まってきたら、表紙ページの背景を写真＋ネイビー暗幕に差し替え（`visual-direction.md`）。

---

## つまずきポイント

- **文字がはみ出す** → テキスト枠を「自動サイズ」or「テキストを枠に合わせる」に。CSVの本文を短くしてもOK。
- **フォントが反映されない** → ブランドキットのフォントを各枠に再適用。
- **市松にならない** → 偶数番の投稿は背景A/Bを入れ替えるか、気にせず統一でもOK。
- **Instagram連携できない** → プロアカウント（ビジネス/クリエイター）になっているか確認。
