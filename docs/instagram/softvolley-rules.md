# ソフトバレーボール 競技規則・ルール要点（投稿の裏取り用）

Instagram のルール・運営系投稿を作るときの**正確さの参照元**。
出典：**公益財団法人 日本バレーボール協会 制定「ソフトバレーボール競技規則」**の
おもな事項の抜粋（松江市八束公民館 配布資料 2016年版をもとに整理）。
※細則・最新改定は必ず日本バレーボール協会の原本を確認すること。

## Ⅰ. 施設と用具
- **コート**: 13.40m × 6.10m の長方形。周囲に最小2mのフリーゾーン。
- **ライン幅**: 4cm（サービスゾーンを区画するライン以外はコート内に含む）。
- **ネット**: 幅80cm、**高さ 2m**。バドミントン用ネット、またはソフトバレーボール用ネットを使用（＝バドミントンコートで実施できる）。
- **ボール**: ゴム製、重さ **210g±10g**、円周 **78cm±1cm**（日本バレーボール協会制定球）。

## Ⅱ. チーム
- **1チーム 4人**（監督1人、キャプテン含む選手4人＋交代選手4人以内）。監督は選手兼任可。
- 競技は4人で行うが、**その4人の年代・性別の組合せは自由**。

## Ⅲ. 試合の準備と進行
- **トス**: 公式ウォームアップ前に実施。勝者はサービス権かコートを選択。最終（第3）セットは再度トス。
- **公式ウォームアップ**: 各チーム3分（両者同意で合同6分）。
- **ローテーション**: サービス権を得たチームが**時計回りに1つずつ移動**。ローテ順はそのセット中変更不可。
- **タイムアウト**: 1セットにつき**最大2回**、1回**30秒**。連続要求も可。
- **選手交代**: 各セット**4回（4人）以内**。交代選手は1セットに一度だけスタメンと交代でき、再交代は同じ選手とのみ。
- **コートチェンジ**: 第1セット終了後に交替。最終セットは**一方が8点**に達したら直ちに交替（位置はそのまま）。

## Ⅳ. 得点・セット・勝者
- **3セットマッチ**。**2セット先取**で試合の勝者。
- 1セットは**2点差をつけて先に15点**で勝ち。14-14なら2点リードまで続行。**ただし17点で打ち切り**（17点先取が1点差でもセット勝者）。
- 負傷等で交代できない場合、3分の回復タイムアウト。回復しなければ失格・没収（相手に必要点を付与、失格側の既得点は生かす）。

## Ⅴ. プレー上の動作と反則
- **サービス**: サービスゾーン内からバックライトの選手が片手（手・腕）で打つ。**サービスは1回**。打った瞬間にコート（エンドライン含む）やゾーン外に触れない。
- **ボール接触**: ブロックを除き**最大3回**で返す。同一選手の連続2回接触は不可（ブロック除く）。身体のどこに当たってもよいが、静止・つかむ・投げるは不可（明瞭に打つ）。
- **アタックヒット**: サービスとブロック以外で相手へ送る動作。味方のプレー空間内ならどの高さからでも可。
- **ブロック**: ネット上端より上で阻止。オーバーネット不可。**相手のサービスをブロックするのは反則**。ブロックのワンタッチは1本目に数えない。

### 主な反則（正式名称）
| 状況 | 正式名称 |
|---|---|
| サービス時にコート/エンドラインを踏む | **フットフォルト** |
| サーブ順を間違える | **サービス順の誤り** |
| サーブの瞬間にローテ順の位置にいない | **アウトオブポジション** |
| サービスがネット/自陣に落ちる・アウト | **サービスフォルト** |
| 相手サーブをネット上端より高い位置でアタック | **アタックヒットの反則** |
| 相手のサービスをブロック | **ブロックの反則** |
| 接触が最大3回を超える | **オーバータイムス**（＝いわゆる「4回タッチ」） |
| ボールを止める/持つ | **ホールディング** |
| 同一選手が続けて2度触れる（ブロック除く） | **ドリブル** |
| インプレー中にネット/アンテナに触れる | **タッチネット**（※支柱に触れるのはOK） |
| ネットを越えて相手コートのボールに触れる | **オーバーネット** |
| センターラインを完全に越えて相手コートに触れる | **パッシングザセンターライン** |
| 両チームが同時に反則 | **ダブルファウル** |
| 相手のプレーを妨害 | **インターフェア** |

### ボールイン/アウト
- **イン**: 区画線を含むコート内の床に接触。
- **アウト**: 線の完全な外側の床/コート外の物体に接触、アンテナのみに触れる、アンテナ外を通過、ネット下方の空間を完全に通過。

## 投稿での言い回しメモ（この資料で確定できること）
- ネット高は「低め」より **「高さ2m・バドミントンコートでできる」** と具体で言うと伝わる。
- 得点は **「15点先取・2点差・17点打ち切り／3セットマッチ（2セット先取）」** がワンセット。
- 反則名は口語（4回タッチ等）でOKだが、正式名称を添えると信頼感が出る（例：4回タッチ＝オーバータイムス）。
