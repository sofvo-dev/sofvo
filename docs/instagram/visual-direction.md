# ビジュアル方針（正式版）

参考にした世界観：
- **Chen Max**（教育系カルーセル：固定フッターバー＋2色市松＋カード型＋差し色1語）← **メインの型**
- **noyouth_nojapan**（インフォグラフィック：データ・比較を図解）
- **Honda PLAY!**（写真/動画＋極太ゴシックのドカン文字＋固定ロゴ署名）← リール用

決定（2026/06）：
- **一枚絵のAIイラストは不採用**（フリー素材っぽく古く見える）。
- カッコよさの正体は「**固定の署名要素（フッター/ロゴ）＋色の規律（2〜3色）＋極太ゴシック＋テンプレ統一**」。イラストの有無ではない。
- **メインは教育系カルーセル（Chen Max型・写真ほぼ不要）**。Tips/解説/比較に最適で、保存されてフォロワーの質が上がる。
- **リールは Honda型（アプリ画面録画＋極太文字）**。機能・動きの実演に使う。
- 2スタイルでも、**色・フォント・フッター・ロゴを固定**すれば1ブランドに見える。

| 参考 | Sofvoが採るポイント |
|---|---|

## ★ Sofvoカルーセル共通テンプレ（Chen Max型・これが backbone）

Canvaで**1個テンプレを作って使い回す**。毎回ゼロから作らない。

### 色（2色市松＋差し色）
- 背景A：**ネイビー `#1B3A5C`**（文字＝白）
- 背景B：**クリーム `#F7F5EF`**（文字＝ネイビー）
- 差し色：**ゴールド `#C4A962`**（見出しのキーワード1語、ピル、下線）
- 投稿ごとにA/Bを交互にすると、プロフィールのグリッドが市松で整って見える。

### フォント
- 見出し：**極太ゴシック**（`Dela Gothic One` ／ 代替 `Noto Sans JP` Black / `Zen Kaku Gothic New` Black）
- 本文：`Noto Sans JP` Bold / Medium

### 毎回固定する3点（＝署名・統一感の核）
1. **下部フッターバー**（濃紺帯）：左に♥、中央に決めゼリフ、右に🔖
   - 決めゼリフ（仮）：**「ソフトバレーを、もっと楽しく。」**
2. **ロゴ**：Sofvoロゴ＋小カテゴリ（`大会運営｜チーム募集｜マッチング`）を毎回同じ位置に
3. **カテゴリピル**：右上などに `#大会運営` `初心者向け` `保存版` 等の小タグ

### 表紙スライドの型
```
[カテゴリピル：例 保存版 / #大会運営]
大きな見出し（2〜3行・キーワード1語をゴールド）
（サブ一行）
Sofvoロゴ
──────────────
♥   ソフトバレーを、もっと楽しく。   🔖   ← 固定フッター
```

### 中ページの型
- カード型モチーフ（角丸カード・メモ用紙・ブラウザ枠・ノート罫線）で本文を囲む
- 1ページ＝1メッセージ。文字は詰め込みすぎない
- 最終ページ＝CTA（「プロフィールのリンクから無料で」＋ロゴ）

## ★ リール（Honda型）

参考：**Honda PLAY!**（本物の映像＋極太文字＋固定ロゴ署名）。

決定：
- ベース素材：**①アプリ画面録画・スクショ（主役）／②自分で撮る大会・体育館写真／③ストック写真**。
- 文字：**極太ゴシック**を画面にドカン。キーワードはゴールド。
- **右下にSofvoロゴを毎カット固定**（Honda の「PLAY!」相当）。

## 1. 勝ちパターンの分解（なぜカッコよく見えるか）

```
リアルな写真／動画（ベース）
   ＋ 強い文字組み（極太ゴシック・大きく）
   ＋ 毎回同じ署名（Sofvoロゴを固定位置に）
   ＋ 色トーンの統一（ネイビー寄り）
= ブランドとして一目で分かる・おしゃれ
```

イラストで作らない。**本物の素材に文字を乗せる**のが今回の路線。

## 2. カルーセル具体例：No.7「運営チェックリスト【準備編】」

Chen Max型テンプレで作る場合（背景B＝クリーム、文字＝ネイビー）。

```
■ 表紙
[ピル：保存版 / #大会運営]
大会運営、これで
"抜け"が無くなる。   ← "抜け"をゴールド
〜準備チェックリスト〜
Sofvoロゴ
──────────────
♥  ソフトバレーを、もっと楽しく。  🔖

■ 2枚目（角丸カードで囲む）
□ 会場を予約した
□ 募集を出した
□ エントリーを締め切った

■ 3枚目
□ 対戦表を作った（→Sofvoなら自動）
□ 賞品・賞状を用意した
□ 当日の受付方法を決めた（→QRチェックイン）

■ 4枚目（CTA）
準備、ぜんぶSofvoで完結。
プロフィールのリンクから無料で。
Sofvoロゴ
```
- 各スライドに**下部フッターバーを必ず入れる**（同じデザイン）。
- 「→Sofvoなら〜」で自然に機能へ誘導。売り込みすぎない。

## 3. リール具体例：No.1「対戦表の自動生成」（Honda型）

ベース＝アプリの画面録画。文字＝極太・白＋ゴールド差し。

| 秒 | 画面（ベース） | 乗せる文字 |
|---|---|---|
| 0-2 | 入力前の画面（or 手書き対戦表を一瞬） | **まだ手書き？** |
| 2-10 | チーム数入力→対戦表が自動生成 | **対戦表は、秒で。**（"秒"を金） |
| 10-13 | 完成した対戦表をスクロール | リーグもトーナメントも自動 |
| 13-15 | ネイビー背景＋ロゴ | **Sofvo** ／ 無料・プロフィールから |

- 右下にSofvoロゴを全カット固定。BGMはトレンド音源。
- キャプションは `post-scripts.md` No.1 を使用。

---

## 4. 作り方（ツール）

- **動画（リール）**：Canva か **CapCut**（無料・テロップが作りやすい）。画面録画を読み込み→極太テキスト→ロゴ→書き出し。
- **静止画（カルーセル）**：Canva。
- **フォント**：Canva に `Dela Gothic One` あり。無ければ Google Fonts から入れる。
- **ロゴ素材**：`website/images/`（`icon-flat.svg` 等）の白抜きロゴを使う。

## ★ 写真が増えたら：段階的に進化させる（重要）

今は素材ゼロだが、今後**実際の大会・体育館の写真**が増える前提で設計しておく。
**固定要素（フッターバー・ロゴ・フォント・ネイビー×ゴールド）は変えない**まま、
ベースだけ写真に差し替えていけば、ブランドを壊さず自然にリッチになる。

| 段階 | 状況 | やること |
|---|---|---|
| Phase 1（今） | 写真ほぼゼロ | テンプレ＋文字中心（背景A/B＋カード）。アプリ画面録画でリール |
| Phase 2 | 大会写真が少し貯まる | 表紙の背景を**写真＋ネイビー暗幕**に差し替え（文字・フッターはそのまま） |
| Phase 3 | 写真が豊富 | 写真ベースの投稿を増やし、Kirin風の温度感へ。テンプレは"額縁"として残す |

- ポイント：**テンプレに最初から「写真を入れてもいい枠」を用意**しておく
  （表紙の背景／中ページのカード内）。写真が来たら差し込むだけにする。
- 撮影のコツ：横位置だけでなく**正方形・縦も意識して撮る**（カルーセル＝1:1、リール＝9:16）。
  顔が写る場合は**本人の許可**を取る（大会参加者・主催者）。

## 5. 投稿前チェック（統一感を守る）

- [ ] **下部フッターバー**が入っているか（カルーセル全スライド）
- [ ] 背景はA（ネイビー）/B（クリーム）の2色に収まっているか
- [ ] 見出しは極太ゴシックか（細い・標準ゴシックはNG＝弱く見える）
- [ ] 差し色はゴールド1語に絞れているか（色を増やさない）
- [ ] ロゴが毎回同じ位置か
- [ ] AIの一枚絵イラストになっていないか
