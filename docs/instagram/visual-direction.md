# ビジュアル方針（正式版）：写真／アプリ画面 ＋ 極太ゴシック

参考にしたい世界観：**kirin_brewery**（本物の写真＋文字組み）／
**Honda PLAY!**（本物の写真・動画＋極太ゴシックのドカン文字＋固定ロゴ署名）。

決定（2026/06）：
- **イラスト路線は不採用**（フリー素材っぽく古く見えるため）。
- ベース素材：**①アプリ画面録画・スクショ（主役）／②自分で撮る大会・体育館写真／③ストック写真**。
- 文字：**Honda風の極太ゴシック**。大きい主役ワードを写真の上にドカンと乗せる。
- **毎回同じ位置にSofvoロゴ署名**（Honda の「PLAY!」相当）。これが統一感の正体。

---

## 1. 勝ちパターンの分解（なぜカッコよく見えるか）

```
リアルな写真／動画（ベース）
   ＋ 強い文字組み（極太ゴシック・大きく）
   ＋ 毎回同じ署名（Sofvoロゴを固定位置に）
   ＋ 色トーンの統一（ネイビー寄り）
= ブランドとして一目で分かる・おしゃれ
```

イラストで作らない。**本物の素材に文字を乗せる**のが今回の路線。

---

## 2. Sofvo の「署名スタイル」（毎回固定するルール）

| 要素 | ルール |
|---|---|
| 主役フォント | **極太ゴシック**。Canva の `Dela Gothic One`（超極太・Honda感）推奨。代替：`Noto Sans JP` の Black(900)／`Zen Kaku Gothic New` Black |
| サブ・本文フォント | `Noto Sans JP` Bold（説明・小さい文字用） |
| 文字色 | 基本は**白**。差し色に**ゴールド `#C4A962`**（キーワードの一部だけ金にすると上質） |
| 可読性 | 写真が明るい時は、文字に薄い影 or 写真の下半分に**ネイビーの暗幕（黒〜#0F2440のグラデ）**を敷く |
| ロゴ署名 | **右下に常にSofvoロゴ**（白抜き）を小さく固定。全投稿で位置を変えない |
| 色トーン | 写真全体にうっすらネイビー寄りの補正をかけ、グリッドの統一感を出す |

> アプリの画面は**本物の録画・スクショ**を使う（偽UIを作らない）。

---

## 3. レイアウトの型（2パターンだけ覚える）

### 型A：リール／動画（Honda風）
- ベース：アプリ画面録画（または大会の動画）を全画面
- 中央〜やや上に**主役ワードをドカン**（1〜3文字＋助詞）
- 右下にSofvoロゴ署名
- 例：「まだ手書き？」→「対戦表は、秒で。」と画面に合わせて切り替え

### 型B：カルーセル／単発（写真＋文字）
- ベース：体育館・大会の写真（or ネイビー一色背景）
- 上 or 中央に**極太の見出し**、下に一行サブ
- 右下にSofvoロゴ署名
- 表紙だけ強い言葉、2枚目以降は読みやすさ重視

---

## 4. 投稿①を新路線で作り直し（具体例）

**テーマ**：対戦表の自動生成。ベース＝アプリの画面録画。

| 秒 | 画面（ベース） | 乗せる文字（極太・白＋金差し） |
|---|---|---|
| 0-2 | 対戦表の入力前の画面（or 手書き対戦表を一瞬） | **まだ手書き？** |
| 2-10 | チーム数入力→対戦表が自動生成される録画 | **対戦表は、秒で。**（"秒"だけゴールド） |
| 10-13 | 完成した対戦表をスクロール | リーグもトーナメントも自動 |
| 13-15 | ネイビー背景＋ロゴ | **Sofvo** ／ 無料・プロフィールから |

- 右下にSofvoロゴを全カット通して固定。
- BGMはトレンド音源（リールはこれで伸びが変わる）。
- キャプションは `post-scripts.md` No.1 をそのまま使用。

---

## 5. 作り方（ツール）

- **動画（リール）**：Canva か **CapCut**（無料・テロップが作りやすい）。画面録画を読み込み→極太テキスト→ロゴ→書き出し。
- **静止画（カルーセル）**：Canva。
- **フォント**：Canva に `Dela Gothic One` あり。無ければ Google Fonts から入れる。
- **ロゴ素材**：`website/images/`（`icon-flat.svg` 等）の白抜きロゴを使う。

---

## 6. 投稿前チェック（統一感を守る）

- [ ] ベースは本物の素材か（イラストになっていないか）
- [ ] 主役フォントは極太ゴシックか（細い・標準ゴシックはNG＝弱く見える）
- [ ] 文字は白＋ゴールド差しに収まっているか（色を増やさない）
- [ ] 右下のSofvoロゴが毎回同じ位置か
- [ ] 写真のトーンがネイビー寄りで、グリッドで並べて浮いていないか
