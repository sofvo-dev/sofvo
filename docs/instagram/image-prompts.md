# AI画像生成プロンプト集（挿絵用）

ChatGPT（GPT-4o / DALL·E）にそのまま貼って使う。各プロンプトは
**英語本文＋日本語の補足指示**のセット。生成後は必ず目視チェックすること。

## 共通ルール（毎回守る）

- **ソフトバレー = 柔らかいゴム製の大きめボール・4人制**。指定しないと普通の
  バレーボール（硬い6人制）の絵になる。
- **画像内に文字を入れない**（"no text" を必ず入れる。日本語文字は崩れる）。
  テロップ・見出しは後から Canva で乗せる。
- **ブランドカラー**: ネイビー `#1B3A5C` ／ ゴールド `#C4A962` を差し色に。
- **トーン**: フラットで親しみやすい、地域・ママさん・シニアにも馴染む雰囲気。
- 生成サイズ：リール用は縦長 9:16、カルーセル用は正方形 1:1。

### 共通スタイル接尾辞（各プロンプト末尾に付けてもよい）

```
Flat minimal vector illustration, soft rounded shapes, friendly Japanese community
sports vibe, navy (#1B3A5C) and warm gold (#C4A962) accent colors on light background,
no text, no letters.
```

## 使い方の流れ

```
このプロンプトをコピー
   ↓ ChatGPT に貼る
挿絵を生成（崩れ・誤りがないか目視チェック）
   ↓
Canva で「本物のアプリ画面（画面録画/スクショ）＋AI挿絵＋テロップ」を合成
   ↓
リール／カルーセルとして書き出し → 投稿
```

> アプリの画面そのものは AI で描かない。必ず実機の画面録画・スクショを使う
> （AIは実在しない別UIを描くため）。
