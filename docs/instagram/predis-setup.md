# Predis.ai セットアップ＆運用シート

目的：テキスト・画像・キャプションを Predis.ai に全自動生成させ、
**自分は「テーマ選択→予約」だけ**にする。Sofvoの世界観は最初の登録で固定する。

---

## 0. まず無料で「日本語テスト」（本採用前に必須）

海外製なので**日本語タイポの品質確認が最優先**。
- 無料プランで、生成言語を **日本語(Japanese)** にして1本だけ試作。
- チェック：①文字化け・崩れが無いか ②不自然な改行が無いか ③Sofvoらしく見えるか。
- ダメなら Canva に切替（`visual-direction.md` のテンプレを手動運用）。OKなら以下を本設定。

---

## 1. ブランドキット登録（世界観を固定する核）

Predis の Brand設定に以下を登録する。

| 項目 | 値 |
|---|---|
| ブランド名 | Sofvo |
| カラー（メイン） | ネイビー `#1B3A5C` |
| カラー（背景） | クリーム `#F7F5EF` |
| カラー（アクセント） | ゴールド `#C4A962` |
| ロゴ | `website/images/app_icon_512.png`（または白抜きロゴ）をアップロード |
| フォント | 極太ゴシック系（無ければ Predis 内の太いゴシックを選択）＋本文は標準ゴシック |
| 決めゼリフ（毎回入れる） | ソフトバレーを、もっと楽しく。 |
| ウェブ/CTA | sofvo.com |

- フォントに日本語の極太ゴシックが無い場合：一番太いゴシックを選ぶ（細い文字は弱く見える）。
- テンプレは「文字が主役・余白広め・1色背景」の**シンプル系**を選ぶ（ごちゃごちゃ系は避ける）。

---

## 2. 生成設定（毎回固定）

- 投稿タイプ：**カルーセル**
- 言語：**日本語**
- ブランド：Sofvo（上で作ったもの）
- スライド数：5〜7枚（表紙＋中身3〜5＋CTA）
- トーン：丁寧・親しみやすい

---

## 3. テーマ入力文例（コピペで使う）

Predis は短いテーマ文でも生成するが、**Sofvoの前提を1行足す**と精度が上がる。
雛形 → 末尾の[ ]だけ差し替え。

**雛形：**
```
日本のソフトバレー（4人制）専用アプリ「Sofvo」の公式投稿。読者は大会主催者・チーム・ママさん層。
保存したくなる実用カルーセルを作って。最後はCTA「プロフィールのリンクから無料で(sofvo.com)」。
テーマ：[ここ]
```

**すぐ使えるテーマ20（`content-calendar-30.md` と対応）：**
1. 大会運営の準備チェックリスト
2. 大会当日の進行チェックリスト
3. ソフトバレーと6人制バレーの違い5つ
4. 4人制のポジションと基本の動き
5. 大会当日の持ち物リスト
6. リーグ戦とトーナメントの選び方
7. 初心者が最初に覚える3つのこと
8. 助っ人をお願いするときのマナーとコツ
9. ソフトバレーボールの選び方
10. ケガ予防のウォームアップ5分メニュー
11. 試合で勝つ声かけ・ローテのコツ
12. メンバー募集で人が集まる投稿のコツ
13. 大会の参加費・予算の決め方
14. 体育館を予約するときの注意点
15. 大会の賞品・賞状アイデア
16. スコアシートの書き方の基本
17. チーム内の連絡をスムーズにする方法
18. 大会写真をきれいに撮るコツ
19. 初めて大会に出る人へのアドバイス
20. ソフトバレーあるある

→ ネタ切れ時は `ai-post-generator.md` の「②ネタ出しプロンプト」で20個補充。

---

## 4. 投稿前チェック（30秒）

- [ ] 日本語が崩れていない／変な改行が無い
- [ ] 色がネイビー・クリーム・ゴールドに収まっている
- [ ] ロゴ・決めゼリフが入っている
- [ ] 最後にCTA（プロフィールのリンクから）がある
- [ ] キャプション末尾にハッシュタグ（#ソフトバレー 等）

---

## 5. 予約・配信（あなたの作業はここだけ）

1. Predis に Instagram アカウント（`sofvo.official`／プロアカウント）を連携。
2. 生成 → 軽くチェック → **予約日時を指定**。
3. **月初にまとめて4〜8本**生成・予約しておくと配信が途切れない（週1〜2ペース）。

> Predis から直接投稿できない場合の保険：画像を書き出して Meta Business Suite で予約。

---

## 6. うまくいかない時

- 日本語が崩れる → 言語設定が日本語か確認／別テンプレに変更／それでもダメなら Canva。
- 世界観がズレる → ブランドキットの色・ロゴが適用されているか確認。テンプレを固定する。
- 文章が硬い／宣伝臭い → テーマ文に「親しみやすく・売り込みすぎない」を足す。
