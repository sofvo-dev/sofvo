# Sofvo Instagram 運用メモ

Sofvo（ソフトバレー特化・日本初のオールインワンアプリ）を普及させるための
Instagram 運用方針・素材まとめ。

## このフォルダの中身

| ファイル | 内容 |
|---|---|
| `README.md` | 戦略の全体像（この文書） |
| `post-scripts.md` | 最初の4投稿の台本（リール／カルーセルの秒割り・テロップ・キャプション） |
| `image-prompts.md` | ChatGPT に貼れる画像生成プロンプト集（挿絵が必要な箇所ぶん） |

## 基本方針（2026/06 決定）

- **目的**: フォロワー数より「実ユーザー獲得」。IGは信頼の置き場、獲得はDMで個別に。
- **リソース**: 週1〜2でコツコツ（バズ狙いではなく継続重視）。
- **メインの動き**: 「使い方」投稿で信頼を作る → DMで使ってくれそうな人を能動的に探す。
- **素材**: ほぼゼロから。アプリ画面録画＋テロップで作れるものを優先。

## アカウントの核

「ソフトバレーの情報が集まる場所」にして、その中でSofvoを自然に使ってもらう。
単なる宣伝アカウントにしない。

> プロフィール案
> **Sofvo｜ソフトバレーをもっと楽しく**
> 🏐 全国の大会・チーム募集・対戦表づくりを、アプリひとつで
> 📲 大会運営／メンバー募集の悩み、Sofvoが解決
> 👇 アプリDL・Web版はこちら（sofvo.com）

## 投稿の4本柱（比率の目安 ①4：②3：③2：④1）

| 柱 | 内容 | 狙い |
|---|---|---|
| ① お役立ち | 対戦表の組み方、大会運営のコツ、ルール豆知識 | 保存・フォロー獲得 |
| ② 機能紹介 | 自動対戦表・チェックインQR・スコア入力の実演 | アプリ理解→DL |
| ③ コミュニティ | 大会レポ、ユーザー紹介、募集の拡散 | 当事者意識・UGC |
| ④ 中の人・世界観 | 開発の想い、アップデート告知、あるある | 親近感・継続接触 |

## DM獲得の進め方（本命）

**誰に**: `#ソフトバレー` `#ママさんバレー` `#ソフトバレーボール` `#地域名+バレー`
で最近投稿している人・チーム。特に「大会やりました」「メンバー募集中」の人が最優先。

**鉄則**:
- いきなり「使ってください」はNG。まず相手の投稿に共感してから。
- 1日5〜10件まで（開設直後は厳守。新規アカは凍結されやすい）。
- コピペ感を消す（相手の投稿内容に1行触れる）。

**DMで送るURL**: `sofvo.com`（新規LPは不要。既存LPで十分）。
計測したい場合は `sofvo.com/?from=ig` のようにパラメータを付ける。

## LPについて

新規制作は不要。`website/index.html`（sofvo.com）にヒーロー・機能紹介・CTAが
揃っている。DMからの冷たい流入向けに、将来「主催者特化の一枚LP」を作るのは
反応を見てからで十分。

## 画像の作り方（役割分担）

| 必要な画像 | 作り方 |
|---|---|
| アプリの画面 | 実機の画面録画／スクショ（AIに描かせない＝本物を使う） |
| テロップ・見出しの日本語文字 | Canva で文字入れ（AI画像内の日本語は崩れる） |
| 挿絵・背景 | ChatGPT 等で生成（`image-prompts.md` のプロンプトを使う） |
| レイアウト合成 | Canva（本物のアプリ画面＋AI挿絵＋テロップ） |

- Codex は画像生成不可（コーディング用）。画像生成は ChatGPT（GPT-4o/DALL·E）。
- ソフトバレーは「柔らかいゴム製ボール・4人制」を明示しないと普通のバレーの絵になる。
- AI生成画像は崩れ・誤りが混ざるため投稿前に必ず目視チェック。
