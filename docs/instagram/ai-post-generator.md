# AI投稿ジェネレーター（続けるための仕組み）

投稿が止まらないように、**AI（ChatGPT / Gemini / Claude）に投稿の中身を生成させる**ための
プロンプト集。AIは「コピー・構成・キャプション」を作る担当。**見た目はCanvaの固定テンプレ**
（`visual-direction.md`）で作るので、毎回ブランドが揃う。

> なぜこの分担か：AIに一枚絵を描かせると古く・ダサくなる。文字／構成はAIが得意。
> だから「中身＝AI」「デザイン＝Canvaテンプレ」に切り分ける。

---

## 使い方（3ステップ）

```
1. 下の「① 投稿生成プロンプト」をAIに貼り、[テーマ] を書く
2. 出てきた構成を Canva テンプレに流し込む（背景A/B・フッター・ロゴは固定）
3. キャプション＆ハッシュタグをコピペして投稿
```

ネタが尽きたら「② ネタ出しプロンプト」で20個まとめて補充。
月初に「③ 1ヶ月まとめ生成」で4〜8本を一気に作ると、配信が途切れない。

---

## ① 投稿生成プロンプト（1本ぶん・これがメイン）

AIに貼って、最後の [テーマ] だけ書き換える。

```
あなたはInstagram運用のプロです。日本のソフトバレー（柔らかいゴム製ボール・4人制の
レクリエーション）専用アプリ「Sofvo」の公式アカウントの投稿を作ります。

# Sofvoとは
ソフトバレー特化のオールインワンアプリ。大会作成・エントリー管理・対戦表の自動生成・
リアルタイムスコア・順位表の自動計算・QRチェックイン・PDF出力・メンバー募集・チャット・
戦績ランキング。Web版(sofvo.com)あり。無料。

# 読者（ターゲット）
ソフトバレーの主催者・運営、チーム/プレイヤー、ママさん・シニア・地域クラブ。
売り込みは控えめ、まず役に立つこと。

# トーン
誠実・上品だが親しみやすい。専門用語は噛み砕く。

# ブランド・デザイン制約（必ず守る）
- 色：ネイビー#1B3A5C / クリーム#F7F5EF / 差し色ゴールド#C4A962
- 見出しは極太ゴシック想定。短く強く。
- カルーセルは下部に固定フッター「ソフトバレーを、もっと楽しく。」が入る前提。
- 各投稿の最後はCTA「プロフィールのリンクから無料で（sofvo.com）」。
- 機能の押し売りはしない。「→Sofvoなら」と自然に1回触れる程度。

# 出力フォーマット（このとおりに出す）
1. 投稿タイプ：カルーセル or リール（テーマに適した方を選ぶ）
2. 4本柱のどれか：①お役立ち／②機能紹介／③コミュニティ／④世界観
3. 背景：A(ネイビー) or B(クリーム)
4. カテゴリピル：例「保存版」「#大会運営」「初心者向け」
5. 表紙コピー：2〜3行。ゴールドにする「キーワード1語」を【】で囲んで指定
6. 中ページ：1ページ1メッセージで3〜5枚ぶん（各ページの文字を箇条書き）
7. CTAページの文言
8. Instagramキャプション：120〜200字。最後にCTA一行
9. ハッシュタグ：8〜12個（#ソフトバレー 等の基本＋テーマ別）

# テーマ
[ここにテーマを書く。例：大会当日の受付をスムーズにするコツ]
```

## ② ネタ出しプロンプト（ネタ切れ防止）

```
上のSofvoの前提（ターゲット・4本柱）を踏まえて、Instagram投稿のテーマ案を20個出してください。
条件：
- 4本柱（①お役立ち ②機能紹介 ③コミュニティ ④世界観）にバランスよく振り分ける
- ソフトバレーの主催者・プレイヤー・ママさん層が「保存したくなる」実用ネタを優先
- すでにある定番（対戦表自動生成・運営チェックリスト・6人制との違い・持ち物リスト）は除外
- 各案に「柱」「想定タイプ(カルーセル/リール)」「一言の狙い」を付ける
```

---

## ③ 1ヶ月まとめ生成プロンプト（配信を途切れさせない）

```
上のSofvoの前提で、今月ぶんのInstagram投稿を【4本】作ってください。
- 4本柱からバランスよく（お役立ち2・機能1・コミュニティ or 世界観1 など）
- それぞれ「① 投稿生成プロンプト」の出力フォーマットで完全な形で出す
- 4本を並べたとき、テーマが被らないようにする
- 配信順のおすすめも最後に書く
```

> 出てきた4本をCanvaテンプレに流し込み、Instagram（or Canvaの予約投稿）で
> **まとめて予約**しておくと、毎週手を動かさなくても配信が続く。

---

## 続けるためのルール（運用が止まらないコツ）

- **月初に③でまとめ生成 → まとめてCanva化 → まとめて予約**。これが一番続く。
- ネタは②で常に20個ストックしておく（`content-calendar-30.md` に追記）。
- 完璧を目指さない。テンプレに流すだけで70点は出る前提で量を回す。
- 写真が貯まってきたら、表紙の背景を写真に差し替える（`visual-direction.md` の段階的進化）。
- 予約投稿ツール：Instagram（プロアカウントのプランナー）/ Canva の Content Planner / Meta Business Suite。

---

## 画像をAIで作りたい場合の線引き（重要）

- **一枚絵のイラストをAI生成 → 不採用**（古く・ダサくなる。テンプレで作る）。
- AIに任せていいのは：**文字・構成・コピー**（このファイルのプロンプト）。
- 写真の代替が要るときだけ：Canvaのストック写真 or AI"写真"を背景に使い、上にテンプレを重ねる
  （単体では使わない。必ずフッター・ロゴ・文字を乗せてブランド化する）。
