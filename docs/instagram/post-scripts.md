## 投稿① リール｜「対戦表、まだ手書きですか？」

主力。最初の1本はこれ。尺15〜20秒。

| 秒 | 画面 | テロップ |
|---|---|---|
| 0-2 | 手書き対戦表（バツ印）※AI挿絵 | まだ手書きで作ってますか？🖊️ |
| 2-5 | Sofvo起動→大会選択 | ソフトバレー専用アプリ「Sofvo」なら |

| 12-17 | リーグ/トーナメント切替 | リーグもトーナメントもワンタップ |
| 17-20 | ロゴ＋CTA | 詳しくはプロフィールのリンクから👆 |

**キャプション**

> プロフィールのリンクから無料で使えます👆
