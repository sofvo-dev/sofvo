⚠️

リジェクト頻出パターンと対策

1
UGC（ユーザー生成コンテンツ）未対応

原因: 通報・ブロック機能がない、または審査者に見つけにくい
対策: 投稿・チャット画面に通報ボタンを配置。審査メモに「通報機能は各投稿の...メニュー内にあります」と記載

2
テストアカウント未提供（Apple）

原因: ログインが必要なアプリでテストアカウントを提供しない
対策: 審査メモにテスト用のメール/パスワードを記載。サンプルデータも用意

3
アカウント削除不備

原因: アカウント削除機能がない、または見つけにくい
対策: 設定画面から2タップ以内で削除できるようにする

4
メタデータ不一致

原因: スクリーンショットと実際の画面が異なる
対策: リリースビルドの実機から直接スクリーンショットを撮影

5
プライバシー申告の不整合

原因: App PrivacyやData Safetyの申告と実際のデータ収集が一致しない
対策: Firebase SDKが自動収集するデータも含めて正確に申告

ビルドコマンドまとめ

iOS ビルド

# 1. 依存関係のインストール
cd ~/Desktop/sofvo
cd ios && pod install && cd ..

# 2. Xcodeでビルド＆アーカイブ
open ios/Runner.xcworkspace
# Product → Clean Build Folder (Shift+Cmd+K)
# Product → Archive
# Organizer → Distribute App → App Store Connect

# または deploy.sh を使用
./deploy.sh ios

Android ビルド

# 1. AABをビルド
cd ~/Desktop/sofvo
flutter build appbundle --release

# 出力: build/app/outputs/bundle/release/app-release.aab

# 2. Play Console にアップロード
# または deploy.sh を使用
./deploy.sh android

iPad スクリーンショット作成

# iPhoneスクリーンショットをiPad用(2064x2752)にリサイズ
mkdir -p ~/Desktop/アプリ化資料/ipad
for f in ~/Desktop/アプリ化資料/2_*.jpg; do
  name=$(basename "$f" .jpg)
  sips -z 2752 2064 "$f" \
    --out ~/Desktop/アプリ化資料/ipad/${name}_ipad.jpg
done
